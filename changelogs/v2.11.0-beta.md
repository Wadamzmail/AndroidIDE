# AndroidIDE Version v2.11.0-beta Changelog

## Important note

  Some features are moved from Android Code Studio / CodeOnTheGo
  Please open an issue if you faced any problems in this release

## Additions

 - Asset Studio
 - Submodule maker
 - New templates based on version catalog 
 - Dependencies updater
 - IDE Configurations ( cmake, ndk) 
 - Added new editor colorSchemes
 - Kotlin inline variable code action
 - New layout-editor
 - Manage git branches
 
## Removals
 
 - Kotlin named arguments completions

## Bug fixes

 - Failed to apply build variants
 - Flickering code when font size is small 

## Improvements

 - Improve kotlin lsp analysis


We believe that you'll have a delightful experience using AndroidIDE v2.11.0-beta!
