# AndroidIDE Version v2.10.0-beta Changelog

_This is a template changelog_

## Important note

 - Please use Jetpack Compose BOM version 2026.5.01 to avoid any issues with compose preview
 - Note that's Jetpack Compose preview is not working for AGP 9.x for now

## Additions

 - no need to initialize the project with gradle every time you opened it. AndroidIDE will save the sync data and reuse it every time you open the project
 - Add Jetpack Compose preview
 - Git integration  `push`, `pull`, `show commpit history`, `view diffs`
 - new kotlin code actions `find usages`, `extract method `, `extract variable `
 - new java code action `SurroundWithTryCatch `
 - add `Recent projects screen`, `Delete projects screen `
 - new Git Preferences in settings
 - update the idescript to download `37.0.0` build-tools, `37.0` platform sdk
 
## Removals 

 - removed SDKs 34,33 from idesetup script
 
## Improvements

- Improve the editor bottomsheet

We believe that you'll have a delightful experience using AndroidIDE v2.10.0-beta
